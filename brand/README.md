# Logo

A bunga raya (Malaysia's national flower) drawn as five drops of scent, in the colours of the Jalur Gemilang.
The logo has the same colours in light and dark mode.

| File | Use |
|---|---|
| `logo.svg` | Main mark (header, loader). The white line in one petal is part of the mark. |
| `logo-small.svg` | 16–32 px (favicon): no white line, bigger yellow centre. |
| `app-icon.svg` | Phone home screen icon, on flag blue. |

Colours: red `#CC0001`, yellow `#FFCC00`, blue `#010066`, white `#FFFFFF`.
Minimum size: 24 px for `logo.svg`; use `logo-small.svg` below that.
The site copies are in `public/` (`logo.svg`, `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`).
